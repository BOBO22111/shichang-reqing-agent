数据来源与计算口径

以下说明用于解释页面上每个数字是怎么来的

数据来源

全部行情来自各大平台公开行情接口（USDT 永续合约口径），无需密钥，不登录、不绑定任何账户。

热点分数

由 24 小时涨跌幅、成交额、换手强度、波动幅度四项各自在全市场中的百分位排名加权得出，权重分别为 30%、30%、20%、20%。成交额先取对数再排名，避免大币与小币量级差距过大。

换手强度

公开行情接口不提供流通量与流通市值，因此无法计算标准口径的换手率。本项目改用 换手强度 = 24 小时成交额 ÷ 持仓量美元值 作为替代，衡量资金周转的快慢。

波动幅度

＝（24 小时最高价 − 最低价）÷ 最低价。该字段仅综合平台口径提供；切换到不提供该字段的数据源时，页面该列显示「—」并说明原因，不做估算、不填假数。

情绪五档

由上涨家数占比（40%）、成交额加权涨跌幅（30%）、高热度币种占比（30%）合成情绪指数，并对资金过度集中于大饼的情形做避险扣分，再映射为狂热 / 活跃 / 中性 / 低迷 / 恐慌五档。

与恐慌贪婪指数的区别

常见的恐慌贪婪指数是单一资产视角，主要看大饼自身的波动率、动量与社媒情绪。本项目是全市场横截面视角：统计 200 多个币种的广度结构，再叠加资金在大饼与小币之间的流向。本项目不采集任何社媒、问卷或舆情数据。

赛道分类

赛道来自项目内置的「币种 → 赛道」映射表，按成交额收录主流币种；未收录的币种归入「其他」，并在页面上如实显示其覆盖情况。

会话内变化

持仓量、成交额占比的变化需要至少两个时间点的数据。页面把你本次打开期间的快照记在浏览器本地，用于计算变化；首次打开时该列显示「—」并提示等待下一次刷新。

取数通道

优先使用站点自带的云端接口代理（带服务端短时缓存与统一错误处理）；检测到云端不可用时，自动切换为浏览器直连，页面顶部会如实显示当前使用的通道。

Agent 形态与官方资源

本作品除网页外，还提供一条命令行入口（agent.mjs），以及一份按币安官方技能规范编写的技能定义（skills/shichang-reqing/SKILL.md）。它可以直接调用币安官方技能市场提供的技能能力取数，也可以读取币安官方开源的公开数据仓库（合约 K 线 + 合约指标，附带持仓量），用来复现已验证过的历史截面；全程不需要 API 密钥，不涉及任何交易操作，不读取账户信息。用法与官方资源逐项取舍见项目根目录的《AGENT.md》。一句话概括：用官方技能包拿数据，用本作品自研的引擎出结论。

数据真实性

页面只展示接口真实返回的数据。接口失败或超时时显示明确的中文失败原因，不会用演示数据或固定数值顶替，也不会把演示数据描述成实时数据。

风险提示

本页面仅用于数字资产市场风险观测与数据分析，不构成投资建议，不代表任何买卖承诺。页面中的热度分数、情绪档位、赛道冷热与资金轮动结论，均为基于公开行情数据的程序化统计结果，不等于实际交易建议。

技术统计是对历史与当期价格的描述，天然存在滞后；行情数据可能存在延迟、缺失或接口波动。本页面不接入交易权限、不保存私钥、不执行任何下单操作，不登录也不读取任何账户信息。

市场有风险，投资需谨慎。任何投资决策应结合个人风险承受能力、资金状况与投资目标独立判断，必要时咨询持牌专业机构。过往表现不预示未来收益。
